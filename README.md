# E-Commerce Revenue, Returns & Customer Retention Analysis

## Overview
This project analyzes the UCI Online Retail II dataset to understand sales performance, revenue trends, product demand, customer purchasing behavior, and cancellation patterns.

## Objectives
- Analyze sales and revenue trends.
- Identify top products and markets.
- Investigate cancellations and returns.
- Understand customer retention and repeat purchases.
- Provide actionable business recommendations.

## Tools & Technologies
Python, Pandas, NumPy, Matplotlib, Seaborn, Power BI, Excel.

## Project Structure
- `data/raw/`: Original dataset
- `data/processed/`: Cleaned data and analysis outputs
- `notebooks/`: Data understanding, cleaning, EDA, and insights
- `src/`: Reusable Python code
- `dashboard/`: Dashboard files and screenshots
- `presentation/`: Final presentation
- `documentation/`: Project methodology and data quality notes

## Dataset Source
UCI Online Retail II:
https://archive.ics.uci.edu/dataset/502/online+retail+ii
